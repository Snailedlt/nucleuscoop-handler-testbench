Editor icons for the start page's "Works in your editor" list.

- `vscode`, `vscodium`, `neovim`, `helix`, `emacs`, `jetbrains`, `zed`: from [Devicon](https://github.com/devicons/devicon) (`icons/<name>/<name>-original.svg`, `develop` branch), MIT licence; the logos are their owners' trademarks.
- `notepadplusplus`, `sublime`, `kate`: neutral stand-ins with the editor's initials, not its logo, until Devicon has the icon (Sublime Text: devicons/devicon#1639; Notepad++ and Kate: not requested yet). Swap in Devicon's when it does.
- `lsp`: any other editor with a language-server client.
