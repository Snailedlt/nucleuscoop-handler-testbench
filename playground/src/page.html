      Try it

      Each player's window, launch arguments and file changes, as Nucleus would set them up. Simulated: nothing on your computer is touched, and the game itself still needs a test in Nucleus. How: the handler is loaded and Game.Play runs once per player in this browser, following the Jint 2.11.58 rules Nucleus uses (checked against the real engine on every probe). File, registry and process calls are recorded, not performed.

      Share

      To get a file for Nucleus, use Save (Ctrl+S).

      1. Open Nucleus Co-op and drag the file onto the Extract handler button (the box-with-arrow icon next to the game list).
      2. Nucleus asks to replace the old handler if there is one, then offers to add the game. Pick the game's .exe when asked.

      By hand instead: copy the code into Nucleus Co-op\handlers\, then restart Nucleus.

      Keyboard shortcuts

      The editor uses VS Code's keys. On a Mac, ⌘ instead of Ctrl. Keys with [ ] / \ ; go by position, as in VS Code: on a German, Spanish or Nordic keyboard, press the key where a US keyboard has that one (e.g. Ü for [).
