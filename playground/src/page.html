    What Nucleus would set up for each player: where its window goes, how the game is started, and which settings files it changes. Nothing on your computer is touched. Whether the game actually plays well still needs a real test in Nucleus. How: the handler is loaded and Game.Play runs once per player in this browser, following the Jint 2.11.58 rules Nucleus uses (checked against the real engine on every probe). File, registry and process calls are recorded, not performed.

    Install it in Nucleus Co-op

    1. Save the file: .
    2. Open Nucleus Co-op and drag the file onto the Extract handler button (the box-with-arrow icon next to the game list).
    3. Nucleus asks to replace the old handler if there is one, then offers to add the game. Pick the game's .exe when asked.

    Prefer doing it by hand? Copy the handler and paste it into Nucleus Co-op\handlers\, then restart Nucleus.
