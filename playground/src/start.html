What it catches

  • Lines Nucleus quietly ignores. A misspelled option or Player.ProtoController5 (only 1–4 exist) runs without an error and does nothing. 16 verified Hub handlers have that one.
  • Code Nucleus can't run. Its script engine (Jint 2.11.58) only takes ES5: arrow functions, template literals and includes() break the handler.
  • Calls that stop the session. A misspelled System.IO.File call or a missing argument throws, and Nucleus ends the session. Options in the wrong format (Game.CustomHotkeys) or set too late (Game.MaxPlayers inside Game.Play) do nothing.
  • Hub install pitfalls, Context used outside Game.Play, wrong value types, missing required fields, and more. Many have a one-click fix.

Every check is tested against the real Jint engine (__PROBES__ probes), and every week against the verified Hub handlers: no errors on any of them, and Try it agrees with the real engine.

Try it in 5 minutes

1. Install

  1. Download __VSIX_NAME__ (__VSIX_TAG__, all releases).
  2. In VS Code: Ctrl+Shift+P → Extensions: Install from VSIX… → pick the file.

Or skip installing: open the workbench.

2. Open a handler you know

Open your handlers folder and pick one that works in Nucleus. Read the warnings and hover over options.

Press ▷ in the editor's top-right corner (Nucleus: Try It) to see each player's setup.

3. Tell us where it's wrong

  • A warning on code that works
  • A real bug it missed
  • Try it saying something Nucleus doesn't do
