What it catches

  • Lines Nucleus quietly ignores. A misspelled option or Player.ProtoController5 (only 1–4 exist) runs without an error and does nothing. 16 verified Hub handlers have that one.
  • Code Nucleus can't run. Its script engine (Jint 2.11.58) only takes ES5: arrow functions, template literals and includes() break the handler.
  • Calls that stop the session. A misspelled System.IO.File call or a missing argument throws, and Nucleus ends the session. Options in the wrong format (Game.CustomHotkeys) or set too late (Game.MaxPlayers inside Game.Play) do nothing.
  • Hub install pitfalls, Context used outside Game.Play, wrong value types, missing required fields, and more. Many have a one-click fix.

Every check is tested against the real Jint engine (__PROBES__ probes), and every week against the verified Hub handlers: no errors on any of them, and Try it agrees with the real engine.

See it

In your editor

  • Suggestions that know your handler: every option Nucleus has with its values, your own functions and variables, and the keys your Game.AddOption lines add. Parameter hints say what to pass.
  • Snippets and a template: type handler in an empty file, or iniset, startargs, eachplayer… where you need them.
  • Test in Nucleus Co-op: one click installs the handler and starts Nucleus with its game selected.
  • Format, rename, go to definition, and a getting-started guide in VS Code. Neovim, Helix, Zed and other editors get the same through ncdev lsp.

Also in the workbench

  • Test all combinations: every player count, input setup and monitor size in one click, with what fails and why.
  • Whole packages: open a .zip or .nc and save it again with its Goldberg files, configs and DLLs.
  • A visual editor beside the code (Form and Blocks), and a debugger that steps through each player.
  • Phones and desktops: symbol keys above the on-screen keyboard; VS Code's shortcuts, hovers and suggestions on a keyboard.
  • WakaTime, if you use it: your handler time in your dashboard (off by default; the code is never sent).

Try it in 5 minutes

1. Install

  1. Download __VSIX_NAME__ (__VSIX_TAG__, all releases).
  2. In VS Code: Ctrl+Shift+P → Extensions: Install from VSIX… → pick the file.

Notepad++: download ncdev.exe from the releases, close Notepad++, and run ncdev setup notepad++ in a terminal as administrator.

Or skip installing: open the workbench.

2. Open a handler you know

Open your handlers folder and pick one that works in Nucleus. Read the warnings and hover over options.

Press ▷ in the editor's top-right corner (Nucleus: Try It) to see each player's setup, then Test in Nucleus Co-op to play it. In Notepad++ both are under Plugins › Nucleus Co-op handlers.

3. Tell us where it's wrong

  • A warning on code that works
  • A real bug it missed
  • Try it saying something Nucleus doesn't do
  • A suggestion or hint that's missing or confusing
