Write Nucleus Co-op handlers with fewer guesses

A Nucleus Co-op handler tells Nucleus how to run a game once for each player. These tools check yours the way Nucleus runs it, explain every option as you type, and show what each player gets, before you start the game. In your browser, VS Code, Notepad++ or any editor.

New to handlers? Make your first one, step by step: a handler for a free game, a few lines at a time, checked as you type, then tested in Nucleus Co-op. Already write them? Get the tools for your editor.

What it catches

  • Lines Nucleus quietly ignores: a misspelled option, or Player.ProtoController5 (only 1–4 exist; 16 verified Hub handlers have it).
  • Code Nucleus can't run: arrow functions, template literals, includes(). Its engine (Jint 2.11.58) only takes ES5.
  • Calls that end the session: a misspelled System.IO.File call or a missing argument. Plus Hub install pitfalls, wrong value types and more, many with a one-click fix.

The docs, one page per option and call, and every check, one page each: what it means, why, an example and the fix. Every check is tested against the real Jint engine (__PROBES__ probes), and every week against the verified Hub handlers: no errors on any of them, and Try it agrees with the real engine.

Or skip installing: the workbench

Everything above in a browser tab, nothing to install, and nothing leaves your browser. Open your handler, an example or any Hub handler. And for when code isn't your thing yet, a visual editor beside the code: options as a form, Game.Play as steps, and every name a handler can use in a list, each with its docs.

Also in the workbench
  • Test all combinations: every player count, input setup and monitor size in one click, with what fails and why.
  • Whole packages: open a .zip or .nc and save it again with its Goldberg files, configs and DLLs.
  • A visual editor beside the code (Form and Blocks), and a debugger that steps through each player.
  • Phones and desktops: symbol keys above the on-screen keyboard; VS Code's shortcuts, hovers and suggestions on a keyboard.
  • WakaTime, if you use it: your handler time in your dashboard (off by default; the code is never sent).
